# Caterpillar

> Caterpillar Inc. (NYSE: CAT) is the world's largest manufacturer of construction
> and mining equipment, off-highway diesel and natural gas engines, industrial gas
> turbines and diesel-electric locomotives. Its digital arm, Cat Digital, publishes
> a developer API estate through the Cat Digital Marketplace covering fleet, asset,
> fuel and worksite telematics built on the Cat Connect and VisionLink platforms.
> The callable surface runs on an Apigee gateway at services.cat.com (mirrored at
> api.cat.com) and is authorized by a PingFederate OAuth 2.0 / OpenID Connect
> server at fedlogin.cat.com. Caterpillar implements ISO 15143-3 (AEMP 2.0), the
> mixed-fleet telematics interchange standard for earth-moving machinery.

Generated by the API Evangelist enrichment pipeline on 2026-09-05 from probed and
searched evidence. Caterpillar does not publish an llms.txt of its own; this file
is not served by Caterpillar. No OpenAPI is published publicly — the Cat Digital
catalog states its APIs meet an OpenAPI specification, but the documents live
inside the subscriber-gated portal.

## APIs

- [ISO 15143-3 (AEMP 2.0) API](https://digital.cat.com/apis/products/prod/iso-15143-3-aemp-20-api): Caterpillar's implementation of the ISO 15143-3 mixed-fleet telematics standard. Base https://services.cat.com/telematics/iso15143 (mirror https://api.cat.com/telematics/iso15143). Endpoints: Fleet Snapshot /fleet/{pageNumber}, Equipment Snapshot /equipment/{equipmentId}, and Timeseries for fault code, location, switch status, cumulative operating hours, cumulative idle operating hours, cumulative fuel used, engine condition and fuel remaining ratio.
- [VisionLink APIs](https://digital.cat.com/api-catalog-overview): Assets Operation, Assets Summary, Faults History, Asset Fence History and Utilization. Base https://services.cat.com/catDigital — e.g. /assetSummary/v1/assets and /faultsHistory/v1/faults. Replaces the legacy VisionLink APIs. Production environment only; there is no sandbox.
- [Cat Digital Marketplace API catalog](https://digital.cat.com/api-catalog-overview): the subscription catalog fronting both families on https://services.cat.com.

## Authentication

- [OpenID Connect discovery](https://fedlogin.cat.com/.well-known/openid-configuration): live, HTTP 200.
- [OAuth 2.0 authorization server metadata](https://fedlogin.cat.com/.well-known/oauth-authorization-server): live, HTTP 200, RFC 8414.
- Token endpoint: https://fedlogin.cat.com/as/token.oauth2 — client_credentials grant, access token expires after 60 minutes, sent as a bearer token in the Authorization header.
- Client id and secret are issued when a Cat Digital Marketplace subscription is approved; Caterpillar says approval takes approximately two weeks.
- Supports PKCE (S256 and plain), PAR, device code, CIBA, token exchange, mTLS client auth and dynamic client registration.
- No /.well-known/oauth-protected-resource (RFC 9728) is served on any host.

## Limits

- 50,000 requests per client id per day, shared across all endpoints, reset at 12:00am GMT.
- General throttle 10 calls/second per client id; Caterpillar recommends staying at 7-8.
- 100 calls/second for Fleet Snapshot, Equipment Snapshot and Fault Codes Timeseries.
- Exhaustion returns HTTP 429 with {"code":"429.002","description":"Quota rate limit exceeded."}.
- No rate-limit response headers are documented or observed, so remaining budget cannot be read at runtime.

## Errors

- Bespoke JSON envelope, not RFC 9457: {"code":"<http-status>.<nnn>","description":"<message>"}.
- Observed live: 401.006 "Missing Authorization header or token value"; 404.001 "No resource for GET <url>".
- Documented: 429.002 "Quota rate limit exceeded."
